# Limb Chaos — облачная сборка JAR

Этот проект подготовлен для сборки через GitHub Actions. Локально Gradle устанавливать не нужно.

## Как получить JAR

1. Войди в GitHub и создай новый репозиторий (например, `LimbChaos`). Можно оставить его Private.
2. Распакуй этот архив на компьютере.
3. Открой репозиторий на GitHub и нажми **Add file → Upload files**.
4. Загрузи **содержимое папки `LimbChaos`**, включая скрытые файлы, если они есть. В корне репозитория должны находиться `build.gradle`, `settings.gradle`, `gradle.properties`, `src/` и `.github/workflows/build.yml`.
5. Нажми **Commit changes**.
6. Открой вкладку **Actions** → workflow **Build Limb Chaos JAR** → **Run workflow** → **Run workflow**.
7. Дождись зелёной галочки. Внизу страницы запуска открой **Artifacts** и скачай `LimbChaos-JAR`.
8. Распакуй скачанный artifact ZIP. Внутри должен быть файл `limbchaos-1.0.0.jar`.
9. Положи JAR в папку `mods` профиля Minecraft Java **1.21.11 Fabric** и установи совместимый Fabric API.

## Важно

- Это **исходный проект с автоматизацией сборки**, а не уже собранный или проверенный JAR.
- Если Actions завершится красным, открой шаг **Build mod**, скопируй первую ошибку и отправь её для исправления. Нельзя считать JAR рабочим, пока облачная сборка не завершилась успешно и мод не проверен в игре.
- Не загружай в публичный репозиторий личные токены или пароли. Для этого проекта они не нужны.
