# Limb Chaos — Minecraft Java 1.21.11 / Fabric

Мемный прототип мода: меню отсоединения конечностей, предметы рук/ног, восстановление и простое применение предметов для удара по мобу.

## Требования
- Minecraft Java 1.21.11
- Java JDK 21
- Fabric Loader 0.18.x
- Fabric API 0.141.1+1.21.11
- Gradle (или Gradle Wrapper, добавленный IDE)

## Сборка JAR
1. Распакуй папку `LimbChaos`.
2. Открой её как Gradle-проект в IntelliJ IDEA.
3. Дождись загрузки Gradle-зависимостей.
4. В терминале проекта выполни:
   - Windows: `gradle build`
   - если проект открыт в IntelliJ и настроен Gradle Wrapper: `gradlew.bat build`
5. JAR появится в `build/libs/limbchaos-1.0.0.jar` (выбирай обычный JAR без `-sources`).
6. Скопируй JAR в `.minecraft/mods`. Установи Fabric API в той же версии.

## Использование
- Нажми `L`, чтобы открыть меню конечностей.
- Кнопка отсоединения выдаёт предмет в инвентарь; если инвентарь полон, предмет выпадает рядом.
- Нажми `L` снова и выбери восстановление. Для восстановления нужен соответствующий предмет в инвентаре.
- Используй предмет конечности по мобу, чтобы нанести небольшой мемный удар.

Команды для теста:
- `/limbchaos detach left_arm`
- `/limbchaos detach right_arm`
- `/limbchaos detach left_leg`
- `/limbchaos detach right_leg`
- `/limbchaos restore left_arm` (аналогично для остальных)

## Важные ограничения первой версии
- Это исходный проект, не готовый проверенный JAR. Сборка в этой среде не выполнялась.
- Визуальное скрытие конечностей сейчас хранится на клиенте и рассчитано на одиночную игру/локальную проверку; в мультиплеере синхронизация внешнего вида между игроками ещё не реализована.
- Визуальный миксин и API GUI зависят от конкретных Fabric/Yarn версий; если Gradle сообщит ошибку API, пришли полный текст ошибки — исправим под установленную сборку.
- Модель игрока скрывает конечность целиком; отдельная анимация отрыва, кровь/частицы и 3D-модели предметов пока не добавлены.

В обычном инвентаре также добавляется кнопка **«Конечности»**. Если кнопка не помещается или отсутствует из-за несовместимости GUI API, открой меню клавишей `L`.
